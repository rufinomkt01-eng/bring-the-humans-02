## O que esta bounty pede

A competição bring-the-humans-02 pede um guia de introdução ao make.fun publicado como README de um repositório público no GitHub. O repositório é a entrada. A pontuação depende de cadastros humanos verificados que usarem seu link de indicação durante a janela da competição.

## Como participar

1. Crie uma conta no make.fun. Você pode entrar com GitHub, Google, Apple, Discord ou carteira Solana. Nenhum método cobra taxa.
2. Vincule seu GitHub ao perfil make.fun para associar o repositório à sua entrada.
3. Acesse a aba Referrals e copie seu código de indicação e o link `https://make.fun/r/<seu-codigo>`.
4. Escolha uma bounty aberta e leia o `RULES.txt` antes de começar.
5. Baixe o kit oficial da bounty, que inclui regras, dados, starter e a CLI `makefun`.
6. Crie um repositório público no GitHub sob sua conta vinculada.
7. Adicione uma licença aprovada pela OSI (recomendado: MIT).
8. Escreva o `README.md` na raiz com as 3 badges make.fun e seu código de indicação.
9. Capture um `screenshot.png` real da página do repositório no GitHub, mostrando o README visível.
10. Faça commit de todos os arquivos na raiz do repositório.

## Regras importantes

- Inicie sua sessão de trabalho apenas após a abertura oficial da bounty. Sessões iniciadas antes da abertura não são aceitas.
- Não copie o starter do kit inalterado. Use-o apenas como estrutura e reescreva o conteúdo com seu próprio agente.

- O screenshot deve ser uma captura real de tela, não um cartão sintético gerado.
- O último submit antes do prazo é o que conta (máximo de 5 por dia, 10 no total).
